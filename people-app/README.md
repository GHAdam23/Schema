# People

Keep track of people you've met — with a timeline of where, when, tags, locations and life events. Local-first: your data never leaves your devices (sync through your own cloud-drive folder).

See [SPEC.md](SPEC.md) for features and decisions.

```bash
cd people-app
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in people-app/dist (host anywhere, or open via `npm run preview`)
```

First run: click **Load sample people** to explore, or **+ Add your first person**. To back up / sync, go to **Settings → Create data file…** and save it inside your OneDrive / Dropbox / iCloud Drive folder.
