# Schema

Lightweight AV / network schematic editor. Read SPEC.md before doing anything — it is the source of truth for features, phases and architecture.

- Owner: Adam Rollin (GitHub GHAdam23). Target browsers: Chrome / Edge.
- Stack: Vite + TypeScript + React, SVG canvas, pdf-lib export (one display list → SVG + PDF).
- Keep SPEC.md updated when decisions change; record which phase items are done.
- Feedback arrives in batches; address the whole list per session.
